# 今日の無料・締切レーダー Implementation Plan

Goal: 公式条件を比較でき、期限切れ・確認不能を応募可能と扱わない静的サイト。
Architecture: JSON正本、共通の状態判定モジュール、Node標準機能によるHTML生成、ブラウザー絞込。GitHub mainからCloudflare Pagesへ公開。
Tech Stack: HTML / CSS / JavaScript / Node 22。外部ランタイム依存なし。
Spec: 本人の2026年11月2日正式着工指令。本計画は一任された実装判断を記録する。

## Global Constraints
- 追加固定費ゼロ。有料API不要。既存他サイトを変更しない。
- 広告はAdsterra専用正式コード取得まで無効、AdSenseなし。
- 日付のみの期限に23:59などを補わない。確認から48時間で再確認待ち。
- 第三者案内と明記。個人情報を収集する独自フォームなし。

## Review Focus
日付境界、期限時刻不明、取得失敗による確認日の水増し、URL重複、保存機能不可の端末。
